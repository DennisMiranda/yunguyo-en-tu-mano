# Code Quality & Formatting

## Rules

- **Context:** All code in this project
- **Rule:** Properties and variable names must be in Spanish (e.g., `categoria_id`, `nombre`, `descripcion`)
- **Rule:** Use Tailwind CSS for all styling
- **Rule:** Components should be reusable and PascalCase in Spanish

## Naming Conventions

- Components: PascalCase in Spanish
- Functions/variables: camelCase in Spanish
- Database columns: snake_case in Spanish

## Formatting Maintenance

- Run `bun run format` before commits
- Check formatting with `npx prettier --check .`
- Update configuration when team preferences change
- Document any custom formatting rules
